1) Kiedy powstał JavaScript (podaj datę).
JavaScript powstał w 1995 roku. Pierwsza wersja została stworzona przez Brendana Eicha w firmie Netscape.

2) Dlaczego jest to język skryptowy?
Ponieważ skrypty JavaScript są wykonywane przez interpreter, bez konieczności wcześniejszego kompilowania całego programu do kodu maszynowego.

3) Gdzie jest wykonywany JS (klient lub serwer)?
JavaScript może być wykonywany po stronie klienta (w przeglądarce) oraz po stronie serwera, np. za pomocą Node.js.

4) Dlaczego JS to bezpieczne narzędzie?
JavaScript działa w środowisku ograniczonym przez przeglądarkę (sandbox), więc skrypt nie ma bezpośredniego dostępu np. do plików użytkownika bez jego zgody.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?
Tak. JavaScript jest językiem obiektowym, ponieważ pozwala tworzyć i używać obiektów, które posiadają właściwości i metody.

6) Wymień zalety JS:
Zaleta 1: Jest szybki i działa bezpośrednio w przeglądarce.
Zaleta 2: Pozwala tworzyć interaktywne strony internetowe.
Zaleta 3: Jest obsługiwany przez większość współczesnych przeglądarek..

7) Framework to:
Framework to gotowy zestaw narzędzi, bibliotek i zasad, który ułatwia tworzenie aplikacji.

8) Do aplikacji mobilnych można użyć Framework:
Można użyć np. React Native.

9) Aplikacje responsywne to:
Aplikacje responsywne to takie, które automatycznie dostosowują swój wygląd i układ do rozmiaru ekranu oraz urządzenia.

10) Przepisz linie kodu, pod nimi wytłumaczenie, jak działa ten fragment kodu:
<input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')">
Tworzy przycisk o nazwie „Nowa Strona”. Po kliknięciu wywołuje funkcję JavaScript WinOpen().

Uwaga:
Gdy chcesz wyświetlić instrukcję, która nie powinna się wykonywać, a tylko wyświetlać, masz do dyspozycji wyświetlanie znaków, które nie będą interpretowane jako instrukcja, czyli > lub <.

Znak < możesz wyświetlić jako &lsaquo;
Znak > możesz wyświetlić jako &rsaquo;

11) Przepisz linie kodu, pod nimi wytłumaczenie, jak działa ten fragment kodu:
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Polecenie otwiera nową stronę lub okno przeglądarki i ustala jego nazwę, rozmiar oraz położenie.>
toolbar=no – ukrywa pasek narzędzi.>
directories=no – ukrywa pasek/katalogi przeglądarki.>
menubar=no – ukrywa pasek menu.>
height=280 – ustala wysokość okna na 280 pikseli.>
width=160 – ustala szerokość okna na 160 pikseli.>
top=200 – ustala odległość górnej krawędzi okna od góry ekranu na 200 pikseli.>
left=200 – ustala odległość lewej krawędzi okna od lewej strony ekranu na 200 pikseli.>

12) Opisz następującą instrukcję window.close()
Polecenie zamyka bieżące okno lub kartę przeglądarki, jeśli przeglądarka zezwala na jego zamknięcie przez skrypt.
